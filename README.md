I design and build whole products end to end, from brand and design system to database and release. I'm a designer first, but I don't work like most designers: I make many variants of even a simple screen, think through every state and edge case the way an engineer would, and then build the result myself.

**Open to design engineer roles** · remote, or relocation for the right team. I do my best work on small, fast teams where decisions are quick and people are trusted.

## 02 · How I work

<picture>
  <source media="(max-width: 600px) and (prefers-color-scheme: dark)" srcset="assets/method-narrow-dark.svg"><source media="(max-width: 600px)" srcset="assets/method-narrow-light.svg"><source media="(prefers-color-scheme: dark)" srcset="assets/method-dark.svg">

</picture>

**AI writes the code. Taste decides what ships.** I lead the design, the UX and the product decisions. Claude Code is the toolchain: one model builds while another plans and reviews. Every project runs the same ten stages, and nothing merges until every gate is green: unit and end-to-end tests, visual-regression baselines and, on Novi Kvadrat, SQL security proofs that are tested themselves.

→ [The method, stage by stage](https://secretocho.design/method/)

## 03 · Why the repositories are private

The code belongs to the products and to the companies behind them, so it lives in private repositories: my own, my studio's, and those of the teams I build for. GitHub still counts the work. Every green square in the graph below this page is a day of it, and the case studies show what it built.
